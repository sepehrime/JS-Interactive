01 First, the foundation

HTML is the structure.

HTML gives each piece of a page a purpose. A heading introduces a topic, a paragraph explains it, and a button invites an action.

These building blocks are called elements. Most elements have an opening tag and a closing tag.

HTML ELEMENTSHTML
<h2>A heading</h2>
<p>A little explanation.</p>
<button>Try me</button>
<img src="photo.jpg"
     alt="A description">

02 Then, make it yours

CSS is the style.

CSS rules choose elements and describe how they should look. A class can style a group; an ID can point to one special element.

SELECTORS + STYLESCSS
.style-sample {
  background: #fff5ed;
  padding: 24px;
  border: 1px solid coral;
}

#styleSample {
  width: 100%;
}

. selects a class · # selects an ID

03 Now, bring it to life

JavaScript adds behavior.

JavaScript can find elements in the page, read what's inside them, and make changes when someone interacts.

04 Find what you need

Select an element.

Before JavaScript can change an element, it needs to find it. Use an ID to select one specific element, or a CSS selector to find an element by its tag, class, or ID.

FINDING ELEMENTSJAVASCRIPT
const title =
  document.getElementById("selectTitle");

const button =
  document.querySelector("#findButton");

06 Make a change

Change the page.

After selecting an element, JavaScript can replace its text. The browser updates the page right away.

CHANGING TEXTJAVASCRIPT
const message =
  document.querySelector("#changeMessage");

message.textContent = "It worked!";

07 Behavior meets appearance

Change a style.

JavaScript can set a style directly. For a reusable appearance, it can add or remove a CSS class instead.

STYLE OR CLASSJAVASCRIPT
box.style.backgroundColor = "lightblue";

box.classList.toggle("highlight");

JavaScript controls behavior. CSS controls appearance.

08 Respond to an action

Listen for an event.

An event is something that happens on a page. A click, typing into a field, or moving a pointer over a box can each trigger JavaScript.

CLICK, INPUT, AND MOUSEOVERJAVASCRIPT
const eventButton = document.querySelector("#eventButton");
const eventInput = document.querySelector("#eventInput");
const hoverTarget = document.querySelector("#hoverTarget");
                        const eventOutput = document.querySelector("#eventOutput");

                        eventButton.addEventListener("click", function () {
                          eventOutput.textContent = "Click event: the button was clicked.";
                        });

eventInput.addEventListener("input", function () {
  eventOutput.textContent = "Input event: you typed \"" + eventInput.value + "\".";
});

hoverTarget.addEventListener("mouseover", function () {
  eventOutput.textContent = "Mouseover event: the pointer entered the box.";
});
TRY EACH EVENT

09 Give it a little information

Read user input.

The input's value is the text the visitor typed. JavaScript checks whether it is empty, then shows either a prompt or a personal greeting.

READ INPUT + MAKE A DECISIONJAVASCRIPT
if (nameInput.value === "") {
  greeting.textContent = "Please enter your name.";
} else {
  greeting.textContent =
    "Hello, " + nameInput.value + "!";
}
YOUR TURN
Leave the field empty or enter a name, then click the button.

The greeting or prompt will appear here.

Try it once with the field empty and once with your name entered.

10 Find a group

Select multiple elements.

querySelectorAll() finds every element that matches a selector. Here it finds all the buttons with the topic-button class.

SELECT A GROUPJAVASCRIPT
const topicButtons =
  document.querySelectorAll(".topic-button");

countOutput.textContent =
  "Found " + topicButtons.length + " buttons.";
