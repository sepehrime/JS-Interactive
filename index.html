01 First, the foundation

HTML is the structure.

HTML gives each piece of a page a purpose. A heading introduces a topic, a paragraph explains it, and a button invites an action.

These building blocks are called elements. Most elements have an opening tag and a closing tag.

HTML ELEMENTSHTML 
<h2>A heading</h2>
<p>A little explanation.</p>
<button>Try me</button>
<img src="photo.jpg"
     alt="A description">
LIVE EXAMPLE
A tiny piece of a page
✦

A little heading

And a sentence underneath it.

This HTML button is an example; it has no action yet.

The browser reads these elements and turns them into the page you see.

How it works

An HTML file is plain text. The browser reads it from top to bottom and turns every tag it finds into an element on the page. Each element has a job: <h1> is the main heading, <p> is a paragraph, <button> is something you can press.

Most elements are written as a pair of tags with content in between:

  1. The opening tag, such as <p>, says where the element starts.
  2. The content is the text (or other elements) inside it.
  3. The closing tag, such as </p>, has a slash and says where it ends.

Some elements, like <img> and <input>, have no content, so they have no closing tag.

More examples

Tags can hold extra information called attributes. An attribute is written inside the opening tag as name="value". Two attributes matter a lot later: id gives one element a unique name, and class puts an element into a group.

ATTRIBUTES: ID AND CLASSHTML 
<h1 id="pageTitle">My first page</h1>

<p class="note">This paragraph is in the "note" group.</p>
<p class="note">So is this one.</p>

<a href="https://example.com">A link to another page</a>

Elements can also sit inside other elements. This is called nesting. A list is a good example: the <ul> element holds several <li> (list item) elements.

ELEMENTS INSIDE ELEMENTSHTML 
<ul>
  <li>Learn HTML</li>
  <li>Learn CSS</li>
  <li>Learn JavaScript</li>
</ul>

<label for="nameInput">Your name</label>
<input id="nameInput" type="text">

The <label> describes the input next to it. Its for attribute matches the input's id, so clicking the label puts the cursor in the field.

Watch out for

  • Forgetting a closing tag. If you leave out </p>, the browser guesses where the paragraph ends, and it may guess wrong.
  • Closing in the wrong order. Close the inner element first: <p><strong>Hi</strong></p>, not <p><strong>Hi</p></strong>.
  • Reusing an id. An id must be unique on the page. Use a class when several elements belong together.

02 Then, make it yours

CSS is the style.

CSS rules choose elements and describe how they should look. A class can style a group; an ID can point to one special element.

SELECTORS + STYLESCSS 
.style-sample {
  background: #fff5ed;
  padding: 24px;
  border: 1px solid coral;
}

#styleSample {
  width: 100%;
}

. selects a class · # selects an ID

LIVE EXAMPLE
Same HTML, with a little style
✦

A little heading

CSS can change the color, spacing, and shape.

.style-sample

The .style-sample class connects this HTML element to a CSS rule.

How it works

A CSS file is a list of rules. Each rule has two parts: a selector that says which elements to style, and a block of declarations in curly braces that says how they should look.

THE PARTS OF A RULECSS 
/* selector */
.note {
  color: gray;          /* property: value; */
  font-size: 14px;
}

Every declaration is a property (what to change), a colon, a value (what to change it to), and a semicolon. The browser goes through every rule and applies it to every element the selector matches.

More examples

There are three selectors you will use all the time. The same three work in JavaScript later, so they are worth learning well.

TAG, CLASS, AND ID SELECTORSCSS 
/* A tag name: every <p> on the page */
p {
  line-height: 1.6;
}

/* A dot + class name: every element with class="note" */
.note {
  background: lightyellow;
}

/* A hash + id: the one element with id="pageTitle" */
#pageTitle {
  color: coral;
}

Spacing is controlled by the box around each element. padding is the space inside the border, border is the line around the element, and margin is the space outside it, between this element and its neighbors.

PADDING, BORDER, AND MARGINCSS 
.card {
  padding: 16px;              /* space inside */
  border: 1px solid #dddddd;  /* the edge */
  margin-bottom: 24px;        /* space outside */
  border-radius: 8px;         /* rounded corners */
}

Watch out for

  • Mixing up . and #. .note looks for a class, #note looks for an id. If nothing changes, check which one the HTML uses.
  • A missing semicolon or brace. One missing ; or } can stop the next lines from working.
  • Forgetting units. Write 16px, not 16. Only 0 works without a unit.

03 Now, bring it to life

JavaScript adds behavior.

JavaScript can find elements in the page, read what's inside them, and make changes when someone interacts.

01 Find an element→ 02 Listen for an action→ 03 Change the page

Where JavaScript lives

JavaScript usually goes in its own file, such as script.js. A <script> tag in the HTML tells the browser to load it. The defer attribute means "wait until the whole page is read before running the script", so every element already exists when your code looks for it.

LINKING A SCRIPT TO THE PAGEHTML 
<head>
  <link rel="stylesheet" href="style.css">
  <script src="script.js" defer></script>
</head>

This website works the same way: open index.html, style.css, and script.js side by side to see all three layers.

The three steps, in one example

Almost every lesson that follows uses the same pattern. Here it is with all three steps in a few lines:

HTMLHTML 
<p id="message">Waiting...</p>
<button id="helloButton">Say hello</button>
JAVASCRIPTJAVASCRIPT 
// 1. Find the elements
const message = document.querySelector("#message");
const helloButton = document.querySelector("#helloButton");

// 2. Listen for an action
helloButton.addEventListener("click", function () {
  // 3. Change the page
  message.textContent = "Hello!";
});

When the visitor clicks the button, the paragraph changes from "Waiting..." to "Hello!". Lessons 4 to 8 take this example apart one step at a time.

A few words you'll see a lot

  • const creates a variable: a name that holds a value, so you can use it again later. const message = ... means "from now on, message is this element".
  • Text in quotes, like "Hello!", is called a string.
  • A ; ends a statement, like a full stop ends a sentence.
  • // starts a comment. The browser ignores it. It's a note for people reading the code.

04 Find what you need

Select an element.

Before JavaScript can change an element, it needs to find it. Use an ID to select one specific element, or a CSS selector to find an element by its tag, class, or ID.

FINDING ELEMENTSJAVASCRIPT 
const title =
  document.getElementById("selectTitle");

const button =
  document.querySelector("#findButton");
TRY IT
1. Click “Select the title” to see what JavaScript found.

I have an ID: selectTitle

Not selected yet. Click “Select the title” to try it.

The outline marks the selected heading; the message shows the text JavaScript read from it.

How it works

document is JavaScript's name for the whole web page. Asking it for an element is like asking "which element on this page matches this description?" The answer is saved in a variable, so you can use the element on the next lines.

  • document.getElementById("selectTitle") takes just the id, with no #.
  • document.querySelector("#findButton") takes a CSS selector, exactly like the ones from lesson 2. That's why it needs the #.
  • If several elements match, querySelector returns the first one.

More examples

Because querySelector understands CSS selectors, it can find elements by tag, class, or id:

THREE WAYS TO SELECTJAVASCRIPT 
// By id: the element with id="pageTitle"
const title = document.querySelector("#pageTitle");

// By class: the first element with class="note"
const firstNote = document.querySelector(".note");

// By tag: the first <button> on the page
const firstButton = document.querySelector("button");

These two lines find the same element. Most people use querySelector for everything, because one method handles every kind of selector.

SAME ELEMENT, TWO METHODSJAVASCRIPT 
const a = document.getElementById("pageTitle");
const b = document.querySelector("#pageTitle");

Watch out for

  • The # rule. querySelector needs # for an id. getElementById must not have it.
  • Spelling and capitals. "#SelectTitle" does not match id="selectTitle". JavaScript is case-sensitive.
  • Nothing found. If no element matches, you get null. Using it later shows an error such as "Cannot read properties of null". That message almost always means the selector is wrong.

05 Read what's there

Elements have content.

The textContent property lets JavaScript read the words inside an element. Try the button to display the paragraph's text below.

READING TEXTJAVASCRIPT 
const paragraph =
  document.querySelector("#readSample");

readOutput.textContent = paragraph.textContent;
TRY IT
JavaScript can read this sentence

I am a paragraph on the page.

Your result will show here.

The text is read with the .textContent property.

How it works

Once you have an element in a variable, you can ask it questions. textContent is one of its properties: a piece of information the element carries. You read it by writing the variable name, a dot, and the property name.

The value you get back is a string: the visible text inside the element, without any tags.

More examples

You can save the text in a variable, then use it somewhere else on the page:

READ, SAVE, AND REUSEJAVASCRIPT 
const heading = document.querySelector("#pageTitle");
const copy = document.querySelector("#copy");

// Read the heading's text and keep it in a variable
const words = heading.textContent;

// Put the same words in another element
copy.textContent = words;

textContent includes the text of everything inside the element. For this HTML, reading the paragraph gives "Hello, world", even though part of it is inside <strong>:

TEXT INSIDE NESTED ELEMENTSHTML 
<p id="greeting">Hello, <strong>world</strong></p>

Watch out for

  • Capital C. It's textContent. textcontent or TextContent gives undefined, which means "there's nothing with that name".
  • Reading the element instead of its text. copy.textContent = heading puts something like "[object HTMLHeadingElement]" on the page. Add .textContent to read the words.

06 Make a change

Change the page.

After selecting an element, JavaScript can replace its text. The browser updates the page right away.

CHANGING TEXTJAVASCRIPT 
const message =
  document.querySelector("#changeMessage");

message.textContent = "It worked!";
TRY IT
Click to update the message

This message is ready to change.

The button click changes textContent in the paragraph.

How it works

Reading and changing use the same property. The difference is which side of the = it's on:

  • On the right of =, you read it: const words = message.textContent;
  • On the left of =, you change it: message.textContent = "It worked!";

The new text replaces everything that was inside the element. The browser redraws that part of the page immediately, so the visitor sees the change right away. The HTML file itself doesn't change. Reload the page and the original text is back.

More examples

You can join strings with + to build a sentence:

BUILDING TEXT WITH +JAVASCRIPT 
const status = document.querySelector("#status");

status.textContent = "Saved at " + "3:15 pm";
// The page shows: Saved at 3:15 pm

Setting the text to an empty string clears it. Inputs work a little differently: their text lives in value, not textContent.

CLEARING TEXT AND INPUTSJAVASCRIPT 
// Remove all the text from an element
status.textContent = "";

// Fill in a text field, then empty it again
const nameInput = document.querySelector("#nameInput");
nameInput.value = "Ada";
nameInput.value = "";

Watch out for

  • Quotes around text. message.textContent = It worked! is an error. Text needs quotes: "It worked!".
  • Spaces when joining. "Hello," + "Ada" gives "Hello,Ada". Add the space inside a quote: "Hello, " + "Ada".
  • Changing too early. If the code runs before the element exists, the selector finds nothing. The defer attribute from lesson 3 prevents this.

07 Behavior meets appearance

Change a style.

JavaScript can set a style directly. For a reusable appearance, it can add or remove a CSS class instead.

STYLE OR CLASSJAVASCRIPT 
box.style.backgroundColor = "lightblue";

box.classList.toggle("highlight");

JavaScript controls behavior. CSS controls appearance.

TRY IT
Choose an action and watch the box change.
A box to brighten

The first button fills the box blue. The second adds or removes a purple outline. Reset restores the starting look.

How it works

There are two ways to change how an element looks:

  1. element.style sets one CSS property directly on the element. It's quick, but the look now lives in your JavaScript.
  2. element.classList adds or removes a class. The look stays in your CSS file, and JavaScript only decides when it applies.

The second way is usually better. If you later want the highlight to be green instead of blue, you change one CSS rule, and every piece of JavaScript that uses the class gets the new look.

More examples

With style, CSS property names lose their dashes and the next letter becomes a capital. Values are strings, and sizes need units:

CSS NAMES IN JAVASCRIPTJAVASCRIPT 
// CSS: background-color   →  JavaScript: backgroundColor
box.style.backgroundColor = "lightblue";

// CSS: font-size           →  JavaScript: fontSize
box.style.fontSize = "20px";

// CSS: border-radius       →  JavaScript: borderRadius
box.style.borderRadius = "12px";

With classList, the look is written once in CSS:

THE CSSCSS 
.highlight {
  background: lightblue;
  border: 2px solid steelblue;
}
THE JAVASCRIPTJAVASCRIPT 
box.classList.add("highlight");     // turn it on
box.classList.remove("highlight");  // turn it off
box.classList.toggle("highlight");  // on if off, off if on

Watch out for

  • No dot in classList. Write classList.add("highlight"), not classList.add(".highlight"). The dot belongs only in CSS selectors.
  • Missing units. box.style.width = "200" does nothing. Use "200px".
  • Dashes in style names. box.style.background-color is an error. Use backgroundColor.

08 Respond to an action

Listen for an event.

An event is something that happens on a page. A click, typing into a field, or moving a pointer over a box can each trigger JavaScript.

CLICK, INPUT, AND MOUSEOVER JAVASCRIPT 
const eventButton = document.querySelector("#eventButton");
const eventInput = document.querySelector("#eventInput");
const hoverTarget = document.querySelector("#hoverTarget");
const eventOutput = document.querySelector("#eventOutput");

eventButton.addEventListener("click", function () {
  eventOutput.textContent = "Click event: the button was clicked.";
});

eventInput.addEventListener("input", function () {
  eventOutput.textContent = "Input event: you typed \"" + eventInput.value + "\".";
});

hoverTarget.addEventListener("mouseover", function () {
  eventOutput.textContent = "Mouseover event: the pointer entered the box.";
});
TRY EACH EVENT
Click the button, move over the box, or type below. Watch the result.

Move your pointer over this box

Click, hover, or type to see an event.

Each action updates the result above so you can see which event JavaScript received.

How it works

addEventListener tells an element: "when this happens to you, run this code". It takes two things in its parentheses:

  1. The event name as a string, such as "click".
  2. A function: the block of code between function () { and } that should run.

The important idea is timing. The code inside the function does not run when the page loads. The browser keeps it and runs it later, every time the event happens. Click five times and it runs five times.

More examples

The three events from the demo, with what triggers each one:

  • "click": the visitor clicks or taps the element (or presses Enter on a focused button).
  • "input": the text in a field changes, once for every key typed or deleted.
  • "mouseover": the mouse pointer moves onto the element.

The input event is great for live previews. This copies whatever you type into a paragraph, letter by letter:

A LIVE PREVIEWJAVASCRIPT 
const titleInput = document.querySelector("#titleInput");
const preview = document.querySelector("#preview");

titleInput.addEventListener("input", function () {
  preview.textContent = titleInput.value;
});

Several elements can each have their own listener, and one element can have more than one:

TWO BUTTONS, TWO LISTENERSJAVASCRIPT 
yesButton.addEventListener("click", function () {
  answer.textContent = "You said yes.";
});

noButton.addEventListener("click", function () {
  answer.textContent = "You said no.";
});

Watch out for

  • Event names have no "on". Use "click", not "onclick". A wrong name is ignored without any error, so nothing happens.
  • Brackets and parentheses. The listener ends with });: the } closes the function, the ) closes addEventListener(.
  • Mouseover on phones. Touch screens have no pointer to hover, so use "click" for anything important.

09 Give it a little information

Read user input.

The input's value is the text the visitor typed. JavaScript checks whether it is empty, then shows either a prompt or a personal greeting.

READ INPUT + MAKE A DECISIONJAVASCRIPT 
if (nameInput.value === "") {
  greeting.textContent = "Please enter your name.";
} else {
  greeting.textContent =
    "Hello, " + nameInput.value + "!";
}
YOUR TURN
Leave the field empty or enter a name, then click the button.

The greeting or prompt will appear here.

Try it once with the field empty and once with your name entered.

How it works

An <input> stores what the visitor typed in its value property. The value is read at the moment the line runs. That's why the code reads it inside the click listener: at click time, the field holds what the visitor typed.

if lets the code make a decision:

  1. The part in parentheses is a question with a yes or no answer. nameInput.value === "" asks "is the field empty?"
  2. If the answer is yes, the code in the first { } runs.
  3. Otherwise, the code after else runs. Exactly one of the two runs, never both.

More examples

=== checks whether two values are exactly the same. Here's a tiny quiz that compares the typed answer with the right one:

CHECK AN ANSWERJAVASCRIPT 
checkButton.addEventListener("click", function () {
  if (answerInput.value === "blue") {
    result.textContent = "Correct!";
  } else {
    result.textContent = "Not quite. Try again.";
  }
});

After using the value, you can clear the field so it's ready for the next entry:

USE THE VALUE, THEN CLEAR THE FIELDJAVASCRIPT 
greetButton.addEventListener("click", function () {
  greeting.textContent = "Hello, " + nameInput.value + "!";
  nameInput.value = "";
});

Watch out for

  • Reading the value too early. const name = nameInput.value; at the top of the file runs once, when the page loads and the field is still empty. Read it inside the listener.
  • = versus ===. One = sets a value. Three === compares two values. Inside if ( ) you almost always want ===.
  • Exact matches. "Blue" === "blue" is false, and so is "blue " === "blue" (extra space). Comparisons are exact.

10 Find a group

Select multiple elements.

querySelectorAll() finds every element that matches a selector. Here it finds all the buttons with the topic-button class.

SELECT A GROUPJAVASCRIPT 
const topicButtons =
  document.querySelectorAll(".topic-button");

countOutput.textContent =
  "Found " + topicButtons.length + " buttons.";
A GROUP OF ELEMENTS
Click the count button to find every matching element.

The result will appear here.

The three labels share the .topic-button class. Click to see how many elements JavaScript finds.

How it works

querySelector stops at the first match. querySelectorAll keeps going and collects every matching element into a list (its proper name is a NodeList).

The list has a length property that tells you how many elements it holds. If nothing matches, you get an empty list with a length of 0, not an error.

More examples

Any CSS selector works, so you can count different groups:

COUNTING GROUPSJAVASCRIPT 
const allItems = document.querySelectorAll("li");
const notes = document.querySelectorAll(".note");
const buttonsInCard = document.querySelectorAll(".card button");

summary.textContent = "There are " + allItems.length + " list items.";

The last selector, ".card button", means "buttons that are inside an element with the class card". That's the same space-separated selector CSS uses.

A list is not a single element, so you can't change all of them at once like this. Lesson 13 shows how to go through the list with a loop and change each one:

THIS DOES NOT WORK (YET)JAVASCRIPT 
// A list has no textContent, so nothing changes:
notes.textContent = "Changed!";

Watch out for

  • Using querySelector by mistake. It returns one element, so .length gives undefined. Check for the word All.
  • Treating the list like one element. notes.classList.add(...) on a list is an error. Loop over it instead (lesson 13).

11 Look behind the scenes

Meet the console.

console.log() prints a message in your browser's Developer Tools. It's a handy way to check what JavaScript is reading or when an event happens.

PRINT A MESSAGEJAVASCRIPT 
console.log("The console demo button was clicked");

Open Developer Tools: right-click the page and choose Inspect, then select the Console tab.

BROWSER CONSOLE
›_ Console

> Click the button to log a message

> Waiting for a click...

>

Click the button. A message appears here and in Developer Tools > Console.

How it works

console.log() prints whatever you put in its parentheses to the console, a panel in the browser's Developer Tools. Visitors never see it. It's your private window into what the code is doing.

  1. Open the page in Chrome, Firefox, Edge, or Safari.
  2. Right-click anywhere and choose Inspect (or press F12, or Cmd + Option + I on a Mac).
  3. Click the Console tab. Messages from console.log() appear here, together with any errors.

More examples

Log a value to see what JavaScript really has. A label in front makes it easy to find:

LOGGING VALUESJAVASCRIPT 
console.log("Hello from script.js");
console.log("Name typed:", nameInput.value);
console.log("Items found:", items.length);

Log inside a listener to check that it runs. If you click and nothing appears in the console, the listener isn't attached (check the selector and the event name):

IS MY LISTENER RUNNING?JAVASCRIPT 
saveButton.addEventListener("click", function () {
  console.log("Save button clicked");
  status.textContent = "Saved!";
});

Reading errors

When something breaks, the console shows a red message with a file name and line number. Two you'll meet often:

  • "X is not defined": JavaScript doesn't know a variable with that name. Look for a typo, or a variable used before the line that creates it.
  • "Cannot read properties of null": a selector found nothing, so the variable holds null. Check the # or . and the spelling of the id or class.

12 Give your code a name

Write a function.

A function is a named block of code. It doesn't run on its own. It runs when you call it by writing its name followed by ().

A parameter is a placeholder inside the parentheses. Each call can pass in a different value, so one function can do a slightly different job each time.

A FUNCTION WITH A PARAMETERJAVASCRIPT 
function sayHello(name) {
  functionOutput.textContent = "Hello, " + name + "!";
}

adaButton.addEventListener("click", function () {
  sayHello("Ada");
});

graceButton.addEventListener("click", function () {
  sayHello("Grace");
});

New concept: parameters. Inside the function, name holds whatever value was passed in: first "Ada", then "Grace".

TRY IT
Both buttons call the same sayHello() function.

Click a button to call the function.

The function is written once and called from two places. Reset calls a second function, resetGreeting(), which has no parameters.

How it works

Writing a function happens in two separate steps:

  1. Define it: function sayHello(name) { ... } gives a block of code a name. Nothing runs yet.
  2. Call it: sayHello("Ada") runs the block. The value in the parentheses goes into the parameter name.

You can call a function as many times as you like, from as many places as you like. When the code inside needs to change, you change it in one place.

More examples

A function without parameters always does the same thing:

NO PARAMETERSJAVASCRIPT 
function clearMessage() {
  message.textContent = "";
}

clearButton.addEventListener("click", function () {
  clearMessage();
});

A parameter makes one function useful in many situations. Here one function shows any message, and three buttons each pass a different one:

ONE FUNCTION, MANY MESSAGESJAVASCRIPT 
function showMessage(text) {
  message.textContent = text;
}

saveButton.addEventListener("click", function () {
  showMessage("Saved!");
});

deleteButton.addEventListener("click", function () {
  showMessage("Deleted.");
});

helpButton.addEventListener("click", function () {
  showMessage("Click Save to keep your work.");
});

Watch out for

  • Forgetting the (). clearMessage; only names the function. clearMessage(); runs it.
  • Quotes around values. showMessage(Saved) looks for a variable called Saved. For text, write showMessage("Saved").
  • Parameter names are local. text only exists inside showMessage. Using it outside gives "text is not defined".

13 Repeat yourself, on purpose

Loop through a list.

An array stores a list of values in square brackets. Each value has a position number, called an index, and the first index is 0.

A for loop repeats code. Here, i starts at 0, the loop keeps going while i is less than the array's length, and i goes up by 1 each time around.

AN ARRAY AND A LOOPJAVASCRIPT 
const topics = ["HTML", "CSS", "JavaScript"];

topics[0];       // "HTML"
topics.length;   // 3

for (let i = 0; i < topics.length; i = i + 1) {
  loopOutput.textContent =
    loopOutput.textContent + "[" + i + "] " + topics[i] + "  ";
}

// querySelectorAll gives a list too, so you can loop over it
for (let i = 0; i < loopCards.length; i = i + 1) {
  loopCards[i].classList.add("is-highlighted");
}

Tip: you'll often see i++ in other code. It's a shortcut for i = i + 1.

TRY IT
The array holds three values. The cards are three HTML elements with the class loop-card.
HTML CSS JavaScript

Pick a button to run some code.

One loop writes every array item into the output. The other visits every card and adds a CSS class to each one.

How it works

A for loop has three parts in its parentheses, separated by semicolons:

  1. let i = 0: the start. Create a counter called i and set it to 0. (let is like const, but the value is allowed to change.)
  2. i < topics.length: the condition. Before each round, check this. If it's true, run the code in { }. If it's false, stop.
  3. i = i + 1: the step. After each round, add 1 to the counter.

With three topics, the loop runs with i as 0, then 1, then 2. When i becomes 3, 3 < 3 is false and the loop ends. Inside, topics[i] picks the item at the current position.

More examples

Go through an array and build one line of text:

JOIN AN ARRAY INTO A SENTENCEJAVASCRIPT 
const colors = ["red", "green", "blue"];
let sentence = "Colors:";

for (let i = 0; i < colors.length; i = i + 1) {
  sentence = sentence + " " + colors[i];
}

output.textContent = sentence;
// The page shows: Colors: red green blue

This is how you change every element from querySelectorAll (lesson 10). The loop visits each one in turn:

CHANGE EVERY ELEMENT IN A LISTJAVASCRIPT 
const notes = document.querySelectorAll(".note");

for (let i = 0; i < notes.length; i = i + 1) {
  notes[i].classList.add("highlight");
}

The last item in any list is at position length - 1, because counting starts at 0:

FIRST AND LASTJAVASCRIPT 
const first = colors[0];                  // "red"
const last = colors[colors.length - 1];   // "blue"

Watch out for

  • <= instead of <. i <= colors.length runs one extra time, and colors[3] is undefined.
  • Loops that never end. If the step is missing, i never grows, the condition stays true, and the tab freezes. Close the tab and fix the step.
  • const for the counter. The counter changes, so it must be let i, not const i.

14 Build the page with code

Create and remove elements.

JavaScript can make brand-new elements. document.createElement() creates one, but it isn't on the page yet. appendChild() puts it inside another element, and then the browser shows it. remove() takes an element off the page.

CREATE, ADD, REMOVEJAVASCRIPT 
// 1. Create a new <li> (not on the page yet)
const newItem = document.createElement("li");

// 2. Give it some text
newItem.textContent = todoInput.value;

// 3. Put it inside the list, so it appears
todoList.appendChild(newItem);

// Later: take it off the page
newItem.remove();

Bonus: each new item also gets its own Remove button, made the same way with createElement("button").

A TINY TO-DO LIST
Add a few items, then remove one.

    Your list is empty. Add your first item.

    None of the list items exist in the HTML file. JavaScript creates each one when you click Add.

    How it works

    Adding an element always takes the same three steps:

    1. Create it with document.createElement("li"). It exists in memory, but it's not on the page yet.
    2. Fill it: set its textContent, add a class, and so on. This is just like changing an element you selected.
    3. Attach it with parent.appendChild(newItem). It goes inside the parent, after any children already there, and appears on the page.

    To take an element away, call remove() on it. It disappears from the page right away.

    More examples

    A new element can get classes and be placed anywhere:

    CREATE A STYLED PARAGRAPHJAVASCRIPT 
    const note = document.createElement("p");
note.textContent = "This paragraph was made by JavaScript.";
note.classList.add("note");

const notesArea = document.querySelector("#notesArea");
notesArea.appendChild(note);

    Combine this with a loop (lesson 13) to turn an array into a list on the page:

    BUILD A LIST FROM AN ARRAYJAVASCRIPT 
    const fruits = ["Apple", "Banana", "Cherry"];
const fruitList = document.querySelector("#fruitList");

for (let i = 0; i < fruits.length; i = i + 1) {
  const item = document.createElement("li");
  item.textContent = fruits[i];
  fruitList.appendChild(item);
}

    New elements can have their own listeners. This is how the to-do demo gives each item a Remove button:

    A BUTTON THAT REMOVES ITS OWN ITEMJAVASCRIPT 
    const removeButton = document.createElement("button");
removeButton.textContent = "Remove";

removeButton.addEventListener("click", function () {
  newItem.remove();
});

newItem.appendChild(removeButton);

    Watch out for

    • Forgetting appendChild. The element is created but never shown. If nothing appears, check this step first.
    • Creating outside the listener. If createElement runs once at the top of the file, every click moves the same element instead of making a new one. Create it inside the listener.
    • Tag names are strings. Write createElement("li"), without the angle brackets.
